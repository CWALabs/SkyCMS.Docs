# Page Builder

Use Page Builder when you want to construct page sections visually using drag-and-drop blocks.

## What You Can Do

- Build page sections with reusable blocks
- Reorder components quickly
- Apply styles visually
- Preview layout behavior before publishing

## When to Use This Editor

- Building landing pages and campaign pages
- Assembling new page sections from existing blocks
- Rapid visual iteration with minimal code

## Main Controls and What They Do

| Control | What it does |
| --- | --- |
| Blocks panel | Shows available section and element blocks |
| Canvas | Main visual workspace for page composition |
| Layers panel | Displays hierarchy and helps with selection |
| Style panel | Applies visual styles to selected elements |
| Device preview | Switches desktop/tablet/mobile preview |
| Save | Saves current page builder draft |

## Common Tasks

### Build a new hero section

1. Open the page in Page Builder.
2. Drag a hero block from the Blocks panel onto the canvas.
3. Select text and image elements to edit content.
4. Adjust spacing and typography in the Style panel.
5. Save and preview.

### Reorder sections on a page

1. Open Layers panel.
2. Drag sections up or down to the desired order.
3. Save changes.
4. Validate desktop and mobile previews.
