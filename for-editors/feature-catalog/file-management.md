# File Management

Use File Management when you need to upload, organize, and maintain media and document files used by your content.

## What You Can Do

- Upload files and images
- Organize folders and naming
- Move, copy, rename, and delete assets
- Open files in code or image editors

## When to Use This Area

- Content preparation before editing pages
- Shared asset housekeeping and cleanup
- Reusing existing assets across multiple pages

## Main Controls and What They Do

| Control | What it does |
| --- | --- |
| Upload | Adds files to the current folder |
| New Folder | Creates a folder for organization |
| Rename | Changes file or folder name |
| Move / Copy | Reorganizes assets across folders |
| Delete | Removes selected files or folders |
| Search | Finds files by name |
| View toggle | Switches between grid and list view |

## Common Tasks

### Upload and place a new content image

1. Open File Manager.
2. Navigate to the destination folder.
3. Select Upload and choose the image.
4. Confirm upload completion.
5. Return to your editor and insert the uploaded image.

### Clean up an old campaign folder

1. Open the campaign folder.
2. Move files that are still needed to archive folders.
3. Delete outdated or duplicate assets.
4. Verify links in active pages are still valid.
