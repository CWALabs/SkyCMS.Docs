# Image Editor

Use Image Editor when you need to prepare images before inserting them into content.

## What You Can Do

- Crop and resize images
- Rotate and flip assets
- Apply adjustments and filters
- Add annotations and basic markup

## When to Use This Editor

- Preparing hero images and article thumbnails
- Correcting dimensions or orientation
- Producing variants for different layout slots

## Main Controls and What They Do

| Control | What it does |
| --- | --- |
| Crop | Trims image boundaries |
| Resize | Changes image dimensions |
| Rotate / Flip | Corrects orientation |
| Adjust | Tunes brightness, contrast, and color values |
| Annotate | Adds text or drawing marks |
| Save | Writes updated image back to storage |
| Export (if available) | Exports a copy with selected format/quality |

## Common Tasks

### Prepare a banner image

1. Open the image from File Manager.
2. Crop to the target banner ratio.
3. Resize to your preferred pixel dimensions.
4. Apply light contrast adjustments if needed.
5. Save and use the updated file in your page.

### Correct a sideways upload

1. Open the image in Image Editor.
2. Use Rotate until orientation is correct.
3. Save.
4. Refresh thumbnail in File Manager if needed.
