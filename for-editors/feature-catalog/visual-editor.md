# Visual Editor

The **Visual Editor** lets you edit page content in place and see the result as you type. It is the fastest path to updating existing text, images, and links without touching code.

<!-- SCREENSHOT: Full Visual Editor view — show the toolbar at the top, a page with editable content regions highlighted, and the Save button visible. Suggested filename: img/visual-editor-overview.png -->

## What You Can Do

- Edit headings, paragraphs, and lists directly on the page
- Insert links, images, tables, and embeds
- Apply formatting (bold, italic, block quotes, headings)
- Save drafts and resume editing later

## When to Use This Editor

- Fast content updates on existing pages
- Authoring blog and article copy
- Non-technical edits that should stay visual

## Main Controls and What They Do

<!-- SCREENSHOT: Toolbar close-up — annotate each button group with a number matching the table below. Suggested filename: img/visual-editor-toolbar-annotated.png -->

| Control | What it does |
| --- | --- |
| Save | Saves your current draft changes |
| Undo / Redo | Reverses or reapplies your latest edits |
| Paragraph / Heading menu | Changes selected text style and hierarchy |
| Bold / Italic / Underline | Applies text emphasis |
| Link | Creates or edits hyperlinks |
| Image | Inserts images from upload or File Manager |
| Table | Inserts and edits table structure |
| Source (if enabled) | Opens the raw HTML source view |

## Common Tasks

### Update body copy on a page

1. Open the page from the [Pages Catalog](../dashboard-overview.md) and click the **Visual Editor** (pencil) icon.
2. Click into the text region you want to change.
3. Edit the text and apply formatting as needed.
4. Click **Save**.
5. Preview and publish when ready — see [Publish a Page](../publish-a-page.md).

### Add an image to a section

1. Place the cursor where the image should appear.
2. Click the **Image** button in the toolbar.
3. Upload a new image or choose one from File Manager.
4. Add alt text for accessibility.
5. Click **Save**.

### Create a link

1. Select the text you want to turn into a link.
2. Click the **Link** button in the toolbar.
3. Paste or type the URL.
4. Choose whether to open in a new tab.
5. Click **Save**.
