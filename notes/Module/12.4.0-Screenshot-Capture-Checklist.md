# SkyCMS 12.4.0 Screenshot Capture Checklist

Purpose: track all requested screenshots for docs updates, then move each item from Pending to Done as files are captured and saved.

Status legend:
- Pending
- Captured
- Placed in docs

## Capture standards

Use the standards in:
- ../screenshot-guide.md

Recommended defaults:
- Full context: 1280 x 720
- Detail crops: 800-1100 px wide
- PNG format

## Save locations (central image store)

All screenshots save to the central image folder at:

  site/assets/images/

This keeps images reusable across multiple doc pages. Use the subfolder that matches the tool or area.

Existing subfolders (use as-is):
- site/assets/images/screenshots/Blogs/
- site/assets/images/screenshots/CodeEditor/
- site/assets/images/screenshots/ImageEditor/
- site/assets/images/screenshots/LiveEditor/
- site/assets/images/screenshots/PageBuilder/
- site/assets/images/screenshots/Templates/

New subfolders created for this release:
- site/assets/images/screenshots/VSCodeExplorer/
